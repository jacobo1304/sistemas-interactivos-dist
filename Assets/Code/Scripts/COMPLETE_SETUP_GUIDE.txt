================================================================================
FIREBASE INITIALIZATION
================================================================================

1. Import Firebase SDK (already done in your project)

2. In Firebase Console:
   - Create Realtime Database (Test Mode or with rules from FIREBASE_RULES.txt)
   - Enable Email/Password Authentication
   - Enable Sign-up (in Auth > Sign-in method)

3. Add Firebase config to project:
   - Download google-services.json
   - Place in Assets/ folder
   - Or use Firebase Editor window to configure

4. Set Database Rules (copy from FIREBASE_RULES.txt):
   {
     "rules": {
       "users": {
         "$uid": {
           ".read": "auth != null && auth.uid == $uid",
           ".write": "auth != null && auth.uid == $uid",
           ".validate": "newData.hasChildren(['username', 'highScore'])"
         }
       },
       "leaderboard": {
         ".read": "auth != null",
         "$uid": {
           ".write": "auth != null && auth.uid == $uid",
           ".validate": "newData.hasChildren(['username', 'score'])"
         }
       }
     }
   }
